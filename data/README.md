- **갱신**: 월 1회, 사람이 포털에서 세 파일을 내려받아(🧑) 새 날짜 폴더에 넣고 `--mode full`로 적재한다 (ADR-025)
- **데이터 기준일**은 파일 안 `데이터갱신시점`의 최댓값이다(적재 시 `data_snapshot.source_updated_max`). 포털 페이지의 "수정일"은 메타데이터 날짜이므로 데이터 기준일로 쓰지 않는다
- **가정**: `데이터갱신시점`에는 시간대 표기가 없다. 한국 시간(Asia/Seoul)으로 읽는다. 원천의 시간대를 확인한 것은 아니다
- 세 파일은 컬럼 구성이 같다(39개). 일반음식점과 휴게음식점·제과점영업은 데이터 기준일이 4일 다르다

- 정규화: 세 파일을 적재한 뒤 `python -m jobs.normalize_licenses`. 서울 밖 주소 행은 여기서 빠진다(`validation.normalize.non_seoul_excluded`). 2026-10 세 파일: `license_record` 704,116건, 약 37초(로컬, 2026-10-13), DV 실패·경고 0
- 2026-10 세 파일 모두 주소에 줄바꿈이 들어간 행은 0건. CSV 형식상 따옴표 안 줄바꿈은 가능하므로 `csv` 모듈 파싱과 픽스처 테스트는 유지한다

## 도로명주소 검색 API 이용 조건 (T-021, 2026-10-13 확인)

**읽은 문서** (모두 2026-10-13에 열어 봄)

1. 주소기반산업지원서비스 「주소정보 API 연계 › 도로명주소 검색 API」 안내 화면 — `https://business.juso.go.kr/jst/jstRoadNmAddrApiSearch`
2. 같은 화면의 "가이드 및 소스 다운로드"(`guide_searchApi.zip`) 안 「[가이드]검색API_활용_방법.pdf」 (압축 파일 안 날짜 2025-12-17)
3. 같은 사이트의 API 신청서 화면(`/jst/jstAddressApiApplicationWrite`)과 신청 내역 화면의 문구
4. 공공데이터포털 15057017 `행정안전부_실시간 주소정보 조회(검색API)` — `https://www.data.go.kr/data/15057017/openapi.do`

**문서에 적혀 있는 것**

| 항목 | 내용 | 문서 |
|---|---|---|
| 비용·이용허락범위 | 무료, "이용허락범위 제한 없음" | 4 |
| 승인키 | 1 시스템 1 승인키. 서비스 용도는 "운영" 또는 "개발(본인인증없이 발급)". 개발 승인키는 사용기간 7일·30일·90일 중에서 고르고, 기간이 끝나면 오류코드 `E0014`("개발승인키 기간이 만료되어 서비스를 이용하실 수 없습니다") | 2, 3 |
| 호출 방식 | POST·GET 둘 다. `countPerPage`는 100 이하. 검색 결과가 9천 건을 넘는 범위는 조회 불가(`E0015`, "리스트 10개 기준 900페이지") | 1, 2 |
| 검색어 제한 | "주소 검색어(keyword)에 SQL 예약어(select, or, union 등) 및 특수문자( <,>,%,= 등)이 포함된 경우에는 서비스 이용이 중단될 수 있습니다." 조치방안: 호출 전에 검색어에서 예약어(or, select, insert, delete, update, create, drop, exec, union, fetch, declare, truncate 등)와 특수문자를 제거 | 2 (이용 주의사항, 4.1 API 차단 사례) |
| 차단 | "모의 해킹 테스트 시 검색API를 호출하시면 IP가 차단 될 수 있습니다." | 2 |
| 트래픽 | "해당 기관의 정책에 따라 트래픽 수는 상이 할 수 있음" — 숫자 없음 | 4 |

**문서에서 찾지 못한 것** (Gate 1 공개 전에 1회 문의하고 답을 여기에 기록한다 — docs/50 §7 Gate 1 체크리스트)

- **호출 한도 숫자**(하루·초당): 위 네 문서 어디에도 없다. 비공식 글 하나(개인 블로그, 2022-01 기준)가 "일 한도 없음, 5초에 10건"이라고 적었으나 공식 문서로 확인하지 못해 코드·설정에 쓰지 않았다
- **검색 결과를 저장하거나 캐시해도 되는지**: 허용한다는 문구도, 금지한다는 문구도 찾지 못했다. 사이트의 이용약관 전문은 읽지 못했다(화면이 스크립트로 그려져 약관 본문 위치를 찾지 못함)

**24시간 캐시가 조건에 맞는가**

- 확인한 범위에서는 **어긋나는 조항을 찾지 못했다**: 이용허락범위가 "제한 없음"이고, 가이드·신청서에 결과 저장을 막는 문구가 없다
- 다만 "허용한다"는 문구를 확인한 것은 아니다. 지금은 캐시를 켠 채로 진행하고(사용자 결정, 2026-10-13), 문의해 답을 받으면 이 절에 날짜와 함께 적는다. 답이 "캐시 불가"면 공개 전에 캐시를 끈다
- 캐시는 프로세스 메모리에만 있고(디스크·DB에 쓰지 않음), 키는 정제한 검색어와 페이지, 값은 API 결과뿐이다(`app/address/cache.py`). 24시간이 지나면 버리고, API 프로세스를 다시 띄우면 비워진다

**지금 쓰는 승인키** (값은 `.env`의 `JUSO_CONFM_KEY`에만 있다. 여기에는 종류와 기간만 적는다)

- 종류: **개발 승인키, 사용기간 90일** (사용자 확인, 2026-10-13)
- 만료일: **2027-01-11** (사용자 확인, 2026-10-13)
- 만료되면 오류코드 `E0014`로 검색이 멈춘다. Gate 1 공개 전에 운영 승인키로 바꾼다(docs/50 §7 Gate 1 체크리스트)

**실제 응답에서 확인한 것** (2026-10-13 녹화, `services/api/tests/fixtures/http/juso/` 9건)

- POST(본문에 승인키·검색어, `resultType=json`)로 정상 응답을 받았다
- 추가 항목(`addInfoYn=Y`, 2건 녹화): `relJibun`(관련지번)은 `서울특별시 광진구 자양동 225-79,화양동 4-1,4-3,…`처럼 쉼표로 이어지고, 시도·시군구는 맨 앞에만, 법정동 이름은 바뀔 때만 적힌다. 산 번지는 `산4-1`. 관련지번이 없으면 빈 문자열. 건물 하나에 관련지번이 수십 개인 경우가 있다. 주소 검색 프록시는 이 항목을 쓰지 않는다(검색 일치율 측정의 불일치 분류에만 쓴다 — docs/50 §7)
- 항목마다 `roadAddr`, `jibunAddr`, `admCd`(10자리 숫자), `mtYn`(`0`/`1`), `lnbrMnnm`, `lnbrSlno`, `bdMgtSn`, `bdNm`이 있다. 값은 모두 문자열이고 건물명이 없으면 `bdNm`이 빈 문자열이다. 본번 필드 이름은 소문자 엘로 시작하는 `lnbrMnnm`이다(안내 화면 표의 `InbrMnnm`은 오기, 가이드 PDF와 실제 응답은 `lnbrMnnm`)
- 산 번지(`신림동 산56-1`)는 `mtYn`이 `1`이다. 결과가 없으면 `errorCode` `0`에 `totalCount` `0`, 시도명만 넣으면 `E0006`

**이 조건 때문에 코드가 하는 일**

- 승인키와 검색어를 **POST 본문**으로 보낸다. 요청 URL이 고정이라 URL이 찍히는 로그·오류 메시지에 승인키가 남지 않는다
- 호출 전에 검색어에서 위 예약어(낱말 단위)와 특수문자를 지운다(`clean_keyword`)
- 테스트·CI는 API를 호출하지 않는다. 실제 응답은 `python -m jobs.record_juso_fixtures`로 녹화하고(호출 7번, 1초 간격), 녹화 파일에는 검색어·페이지·응답만 쓴다

## 법정동코드 파일 (T-011, 2026-10-12 파일을 열어 확인)

- **인코딩** UTF-8, 맨 앞에 BOM(`EF BB BF`). **구분자** 쉼표. **줄바꿈** CRLF. 따옴표로 감싼 값 없음
- **컬럼 7개** (헤더 1행): `법정동코드, 시도명, 시군구명, 읍면동명, 리명, 순번, 생성일자`
- **폐지여부 컬럼이 없다.** 과거 코드·삭제일자 컬럼도 없다. 그래서 폐지여부 값 종류는 기록할 것이 없고, 모든 행을 `abolished=false`로 적재한다
- 20,561행, 모든 행 7열. `법정동코드`는 모두 10자리 숫자이고 중복 0. 값 앞뒤 공백 0

- `생성일자`는 `YYYY-MM-DD`. 최솟값 1988-04-23(4,203행), 최댓값 2026-06-30
- 시도 16개. 서울특별시 493행 = 시도 1 + 자치구 25 + 법정동 467
