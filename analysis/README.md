# analysis — W0 데이터 검증

서비스 코드가 아니라 **설계 근거**다. 스크립트 로직은 수정하지 않는다(재현 기준). 서비스의 `method_version='w0'` 모드가 이 결과를 재현해야 한다(docs/50 §3).

## 1. 데이터

- 행정안전부 식품_일반음식점 (서울특별시 파일), 2026-10-08 다운로드
- 539,589건 (폐업 419,542 / 영업 120,047), 관리번호 고유, 날짜 역전 0건, 폐업인데 폐업일자 없음 27건
- 원본은 저장소에 넣지 않는다(`data/README.md`에 출처·다운로드일 기록)

## 2. 질문

"같은 건물·같은 층에서 과거에 폐업이 잦았던 자리에 새로 연 가게는 더 일찍 문을 닫는가?"

## 3. 정의 (`w0_location_signal.py`)

| 항목 | 정의 |
|---|---|
| 층키 | `시군구 동 본번-부번` + 층 (지번주소 꼬리 + 도로명 상세에서 층 파싱) |
| 과거 폐업 횟수 | 같은 층키에서 해당 가게 개업일 이전에 폐업한 기록 수 |
| 코호트 | 2005-01-01 ~ 2023-10-08 개업, 층키 있음, 면적 > 0, 본인이 일괄 폐업일(서울 전체 하루 100건 이상) 폐업이면 제외 |
| 결과 | 개업 후 3년(1,095일) 안에 폐업 |
| 통제 | 개업 연도, 업태(상위 10 + 기타), log 면적, 시군구, 지하 여부, 2층 이상 여부 |
| 표준오차 | 층키 클러스터 |

## 4. 결과

### 4.1 주소 품질
- 시군구·지번 파싱 99.9%, 층 정보 50.2%(2005년 이후 개업분 82.1%, 구별 최저 노원구 57.9% ~ 최고 용산구 96.2%), 호 정보 18.4%
- 층키 126,288개 중 2개 이상 이력 42.9%, 3개 이상 21.5%. 2개 이상 이력 층키의 업소 중 47.8%가 앞선 업소와 영업 기간이 겹침(같은 층 여러 점포 또는 신고 지연)
- 하루 100건 이상 일괄 폐업일 238일, 44,194건

### 4.2 기준율 (분석 표본 171,077, 전체 3년 내 폐업률 32.1%)

| 과거 폐업 | 0 | 1 | 2 | 3 | 4+ |
|---|---|---|---|---|---|
| n | 102,466 | 33,968 | 13,727 | 6,384 | 14,532 |
| 3년 내 폐업률 | 29.0% | 33.6% | 37.1% | 37.3% | 43.4% |

### 4.3 로지스틱 회귀 (과거 폐업 횟수는 5에서 절단)

| 모형 | 과거 폐업 1회당 오즈비 | 95% CI | p |
|---|---|---|---|
| 기본 통제 | 1.075 | 1.063~1.087 | 2.0e-38 |
| + 같은 건물 다른 층 폐업 통제 | 1.090 | 1.077~1.103 | 5.8e-44 |
| (다른 층 폐업 1회당) | 0.992 | 0.988~0.996 | 1.6e-04 |

→ 건물 전체의 회전율이 아니라 **그 층 자리에 붙은 신호**.

### 4.5 시간 외 검증 (2005–2014 학습 → 2015–2020 개업 예측)

| 모형 | AUC |
|---|---|
| 통제변수만 | 0.6088 |
| + 자리 폐업 이력 | 0.6108 |

검증 기간 실제 3년 내 폐업률: 과거 폐업 0회 30.6% vs 3회 이상 39.8%.

→ **집단 차이는 실재하지만 개별 예측력 증가는 매우 작다.** 위험 점수를 만들지 않는 근거(ADR-005).

### 4.6 광진구 단독 (초기 탐색)
같은 방식(일부 정의 차이)으로 OR 1.19(1.12~1.27, n=5,877). 서울 전체로 다시 돌리면 광진구 1.12 — 초기 탐색값은 서울 평균보다 높은 쪽이었다.

## 5. 호실 연결 기준선 (`unit_chain_baseline.py`, 2026-10-12)

평가: 2000년 이후, 층·호·면적이 있는 기록 54,322건, 층 10,352개, 실제 호실 36,415개

| 방법 | 쌍 정밀도 | 재현율 | F1 |
|---|---|---|---|
| 층 전체 = 한 자리 | 0.120 | 1.000 | 0.214 |
| 시간 겹침 금지 + 면적 ±25% (전체) | 0.566 | 0.225 | 0.322 |
| 층 전체 = 한 자리 (호실 ≤6 층) | 0.269 | 1.000 | 0.424 |
| 시간 겹침 금지 + 면적 ±25% (호실 ≤6 층) | 0.685 | 0.426 | 0.525 |

진단: 같은 호 연속 기록의 28.4%가 30일 넘게 동시 영업(신고 지연·중복 신고로 추정), 27.0%는 면적 차 25% 초과, 47.1%는 면적 완전 일치 → 라벨 노이즈가 크고, 면적 완전 일치가 강한 특징. 화면 표시는 층 단위로 결정(ADR-015).
