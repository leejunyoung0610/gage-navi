# analysis — W0 데이터 검증

서비스 코드가 아니라 **설계 근거**다. 스크립트 로직은 수정하지 않는다(재현 기준). 서비스의 `method_version='w0'` 모드가 이 결과를 재현해야 한다(docs/50 §3).

같은 폴더의 다른 분석: [폐업 시점 분석](closure_timing.md) — 2019~2023년 서울 식품 3종 폐업의 날짜별·월별 몰림과 지원금 일정 대조(재현 스크립트 `closure_timing.py`, ADR-020 관련).

## 1. 데이터

- 행정안전부 식품_일반음식점 (서울특별시 파일), 2026-10-08 다운로드
- 539,589건 (폐업 419,542 / 영업 120,047), 관리번호 고유, 날짜 역전 0건, 폐업인데 폐업일자 없음 27건
- 원본은 저장소에 넣지 않는다(`data/README.md`에 출처·다운로드일 기록)

## 2. 질문

"같은 건물·같은 층에서 과거에 폐업이 잦았던 자리에 새로 연 가게는 더 일찍 문을 닫는가?"

## 3. 정의 (`w0_location_signal.py`)

| 항목 | 정의 |
|---|---|
| 층키 | `시군구 동 본번-부번` + 층 (지번주소 꼬리 + 도로명 상세에서 층 파싱) |
| 과거 폐업 횟수 | 같은 층키에서 해당 가게 개업일 이전에 폐업한 기록 수 |
| 코호트 | 2005-01-01 ~ 2023-10-08 개업, 층키 있음, 면적 > 0, 본인이 일괄 폐업일(서울 전체 하루 100건 이상) 폐업이면 제외 |
| 결과 | 개업 후 3년(1,095일) 안에 폐업 |
| 통제 | 개업 연도, 업태(상위 10 + 기타), log 면적, 시군구, 지하 여부, 2층 이상 여부 |
| 표준오차 | 층키 클러스터 |

## 4. 결과

### 4.1 주소 품질
- 시군구·지번 파싱 99.9%, 층 정보 50.2%(2005년 이후 개업분 82.1%, 구별 최저 노원구 57.9% ~ 최고 용산구 96.2%), 호 정보 18.4%
- 층키 126,288개 중 2개 이상 이력 42.9%, 3개 이상 21.5%. 2개 이상 이력 층키의 업소 중 47.8%가 앞선 업소와 영업 기간이 겹침(같은 층 여러 점포 또는 신고 지연)
- 하루 100건 이상 일괄 폐업일 238일, 44,194건

### 4.2 기준율 (분석 표본 171,077, 전체 3년 내 폐업률 32.1%)

### 4.5 시간 외 검증 (2005–2014 학습 → 2015–2020 개업 예측)

| 모형 | AUC |
|---|---|
| 통제변수만 | 0.6088 |
| + 자리 폐업 이력 | 0.6108 |

검증 기간 실제 3년 내 폐업률: 과거 폐업 0회 30.6% vs 3회 이상 39.8%.

→ **집단 차이는 실재하지만 개별 예측력 증가는 매우 작다.** 위험 점수를 만들지 않는 근거(ADR-005).

### 4.6 광진구 단독 (초기 탐색)
같은 방식(일부 정의 차이)으로 OR 1.19(1.12~1.27, n=5,877). 서울 전체로 다시 돌리면 광진구 1.12 — 초기 탐색값은 서울 평균보다 높은 쪽이었다.

## 5. 호실 연결 기준선 (`unit_chain_baseline.py`, 2026-10-12)

평가: 2000년 이후, 층·호·면적이 있는 기록 54,322건, 층 10,352개, 실제 호실 36,415개

| 방법 | 쌍 정밀도 | 재현율 | F1 |
|---|---|---|---|
| 층 전체 = 한 자리 | 0.120 | 1.000 | 0.214 |
| 시간 겹침 금지 + 면적 ±25% (전체) | 0.566 | 0.225 | 0.322 |
| 층 전체 = 한 자리 (호실 ≤6 층) | 0.269 | 1.000 | 0.424 |
| 시간 겹침 금지 + 면적 ±25% (호실 ≤6 층) | 0.685 | 0.426 | 0.525 |

진단: 같은 호 연속 기록의 28.4%가 30일 넘게 동시 영업(신고 지연·중복 신고로 추정), 27.0%는 면적 차 25% 초과, 47.1%는 면적 완전 일치 → 라벨 노이즈가 크고, 면적 완전 일치가 강한 특징. 화면 표시는 층 단위로 결정(ADR-015).

## 6. 재계산 결과 (T-020에서 추가)

### 6.1 식품 3종 `method_version=2026.10.1`

식품 3종(일반음식점+휴게음식점+제과점영업), 2026-10 세 파일, 기준일 2026-10-07. `jobs.compute_base_rates`가 만든 `reports/base_rates.md`에서 옮겼다(정의는 docs/10 §7.2·§7.3 — 층키는 PNU+층, 층 파서는 docs/10 §3, 급증일은 새 규칙으로 제외, 편의점 제외. §3의 W0 정의와 다르므로 §4와 숫자를 바로 견줄 수 없다).

코호트 250,131건(2005-01-01 ~ 2023-10-08 개업), 3년 내 폐업률 36.11%

| 과거 폐업 | 0 | 1 | 2 | 3 | 4+ |
|---|---|---|---|---|---|
| n | 134,162 | 46,941 | 21,262 | 10,484 | 37,282 |
| 3년 내 폐업률 | 30.93% | 35.40% | 38.11% | 39.39% | 53.61% |

| 항목 | 값 |
|---|---|
| 과거 폐업 1회당 오즈비 (기본 통제, n = 246,030) | 1.101 (1.084~1.118), p = 2.9e-34 |
| + 같은 필지 다른 층 폐업 통제 | 1.108 (1.097~1.120), 다른 층 폐업 1회당 0.997 |
| 시군구별 (구마다 따로 적합) | 25곳 중 OR > 1: 25곳, 95% 구간 하한 > 1: 20곳, 상한 < 1: 0곳 |
| 시간 외 검증 AUC (2005–2014 학습 → 2015–2020) | 0.6192 → 0.6236 |
| 결론 유지 판정 (기본 + 민감도 6개 설정) | 모두 (a)(b) 유지 |
| 층 규모별 판정 | 단독·소형 복수 유지, 대형(10+)은 (b) 깨짐 — OR 1.013 (0.968~1.061) |
| 인허가 종류별 `4+` 폐업률 (참고) | 일반음식점 44.88%, 휴게음식점 62.85%, 제과점영업 67.43% |

- `4+` 버킷은 기록이 많은 층에 크게 좌우된다(37,282건 중 18,106건이 기록 50건이 넘는 층, 그 폐업률 65.90%). 그래서 화면은 층 규모별 값을 쓴다(docs/10 §7.2)
- 개별 예측력 증가는 여전히 작다(AUC +0.0044). 위험 점수를 만들지 않는다는 결론(ADR-005)은 그대로다

### 6.2 W0 재현 테스트 (`tests/integration/test_w0_reproduction.py`, 2026-10-13)

같은 파일(`data/raw/2026-10-08/식품_일반음식점_서울특별시.csv`, SHA-256 `3f3153d0…7e7fef`)로 서비스의 `method_version='w0'`를 계산해 §4.2~§4.5와 견줬다. 기대값과 허용 오차(리포트의 반올림 단위)는 테스트 코드보다 먼저 커밋했다(docs/10 §7.4, docs/50 §3).

- `w0_location_signal.py`를 같은 파일로 다시 돌리면 §4의 숫자가 그대로 나온다(분석 표본 171,077)
- **서비스의 `w0` 모드는 일치하지 않았다**: 코호트 171,495(+418). 허용 오차와 기대값은 고치지 않았다
- **원인 한 가지**: `소재지면적`에 천 단위 쉼표가 든 값(`1,044.37` 등)이 파일에 880건 있다(모두 1,000㎡ 이상, 1,001.95 ~ 90,155.81. 쉼표 없이 1,000 이상인 값은 0건). 스크립트는 `pd.to_numeric`으로 읽어 이 값들이 숫자가 아닌 값이 되고 `면적 > 0` 조건에서 빠진다. 서비스의 정규화(`parse_area`)는 쉼표를 떼고 숫자로 읽어 남긴다. 880건 중 코호트 조건(개업 기간·층키·일괄 폐업일 제외)에 드는 것이 418건이다
- 확인: 공통 171,077건은 과거 폐업 횟수와 3년 내 폐업 여부가 전부 같다. 층·건물 키가 다른 기록은 전체 539,575건 중 0건. 쉼표 면적 880건을 스크립트처럼 값 없음으로 두면 §4.2~§4.5의 재현 대상 전 항목이 반올림 단위까지 일치한다

| 항목 | §4 (스크립트) | 서비스 `w0` (쉼표 면적 포함) |
|---|---|---|
| 분석 표본 / 3년 내 폐업률 | 171,077 / 32.1% | 171,495 / 32.1% |
| 버킷 n (0 / 1 / 2 / 3 / 4+) | 102,466 / 33,968 / 13,727 / 6,384 / 14,532 | 102,765 / 34,023 / 13,743 / 6,394 / 14,570 |
| 버킷 폐업률 | 29.0 / 33.6 / 37.1 / 37.3 / 43.4% | 28.9 / 33.6 / 37.1 / 37.2 / 43.4% |
| 기본 통제 OR | 1.075 (1.063~1.087), p 2.0e-38 | 1.075 (1.064~1.087), p 8.5e-39 |
| 다른 층 통제 OR / 다른 층 폐업 1회당 | 1.090 (1.077~1.103) / 0.992 | 1.090 (1.077~1.103) / 0.992 |
| AUC | 0.6088 / 0.6108 | 0.6088 / 0.6109 |
| 시군구 요약 (OR > 1 / 하한 > 1 / 상한 < 1) | 21 / 18 / 0 | 21 / 18 / 0 |

- 어느 쪽을 기준으로 삼을지(서비스 `w0` 모드가 스크립트의 면적 읽기를 따를지, 기대값을 쉼표 면적을 포함한 값으로 바꿀지)는 아직 정하지 않았다
