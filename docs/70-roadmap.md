## 2. 라벨링 운영

- W2~W7 **주 3시간** + W8 4시간 고정 블록(총 22시간). 공고 1건 평균 약 45분 가정 → 30건
- 순서: **dev 18건을 먼저**(W2~W6), 그다음 test 12건(W6~W8). **test 라벨링은 프롬프트 개발(T-052, W9)이 시작되기 전에 끝낸다.** 분할은 T-060a에서 후보 목록을 만들 때 seed로 한 번 고정
- 형식: T-040(DSL 모델) 전에는 `docs/20 §2.3` 예시 구조를 따른 JSON 파일 + 근거 인용(사람이 직접). T-040 완료 후 전부 스키마 검증해 고치고, T-056에서 `eval_case`로 적재
- W9부터 test 공고는 프롬프트를 고치는 동안 열람·실행하지 않는다(docs/50 §5). 라벨 파일 위치: `eval/labels/{dev,test}/`
