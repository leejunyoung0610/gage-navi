# 40. 프론트엔드 (`apps/web`)

## 1. 디자인 원칙

1. **모바일 우선**: 기준 폭 360px에서 먼저 완성하고 넓힌다. 데스크톱은 최대 폭 720px 단일 열(관리자 화면만 넓게)
2. **큰 글씨·한 화면 한 질문**: 본문 17px, 줄 간격 1.6. 마법사는 화면당 질문 1~3개
3. **숫자가 주인공**: 핵심 숫자(폐업률, 금액, 기한)는 크게, 설명은 그 아래 한 줄
4. **근거는 한 번 탭 거리**: 모든 판단 옆 "근거" 버튼 → 하단 시트
5. **색만으로 의미를 전달하지 않는다**: 배지에는 항상 글자(충족/불충족/확인 필요)
6. **단정하지 않는다**: 통계는 "참고", 판정은 "공고 기준"이라고 항상 표기
7. WCAG 2.1 AA (대비 4.5:1, 터치 영역 44px, 포커스 표시, 폼 라벨)

## 3. 공통 레이아웃

- 헤더: 서비스명, 메뉴(자리 이력 · 정책자금 · 폐업 지원 · 내 사업장)
- 푸터: 데이터 출처(행정안전부 인허가 데이터, 공고 기관), 방법론 링크, "가게내비는 신청을 대행하거나 수수료를 받지 않아요", 정정 요청 안내
- 베타 모듈(게이트 미통과)은 상단에 고정 배너: "베타예요. 결과를 그대로 믿지 말고 공고 원문을 확인하세요."

## 4. 화면 명세

### 4.1 홈 `/`
- 제목: "어떤 결정을 앞두고 있나요?"
- 카드 3개: **계약할 자리 확인하기**(→ 주소 검색 포커스) · **필요한 자금 마련하기**(→ `/funding`) · **폐업 준비하기**(→ `/closure`)
- 저장된 프로필이 있으면: "○○구 · 분식 · 개업 3년차 사장님" 요약 칩 + 수정 링크

### 4.2 주소 검색 (컴포넌트 `AddressSearch`)
- 입력 300ms 디바운스, 2자 이상에서 호출, 결과 최대 10개
- "현재 위치로 찾기" 버튼(Geolocation 권한 요청 → `/address/reverse`), 권한 거부 시 버튼 숨김
- 결과 항목: 도로명 + 지번 + 건물명, `has_history=false`면 회색 + "식품 업소 기록 없음"
- 상태: 로딩(스켈레톤 3줄), 결과 없음("주소를 조금 더 자세히 입력해 주세요"), 오류(재시도 버튼)

### 4.3 필지 `/place/[pnu]`
- 주소, 작은 지도(카카오, 지연 로딩), 층 목록(층 · 기록 수 · 영업 중 수)
- 층이 1개이고 층을 알 수 없는 기록이 없으면 바로 층 페이지로 이동
- `records_without_floor > 0`: 층 목록 아래에 **"층을 알 수 없는 기록 {n}건"** 타임라인을 보여준다(T-018에서 결정, 2026-10-13). 층 정보가 하나도 없는 필지가 157,898곳 중 50,066곳(32%)이라, 이 목록이 없으면 그 필지에서는 가게 이력이 하나도 보이지 않는다
  - 항목은 층 이력 타임라인(§4.4-5)과 같다: 상호 · 업태 · 기간 · 기간 길이 · 배지(영업 중/폐업 처리 몰린 날). 세로, 오래된 순
  - 안내 문구: "신고 주소에 층이 적혀 있지 않아 어느 층의 가게인지 알 수 없는 기록이에요. 층별 이력과 통계에는 포함되지 않았어요."
  - **기준율 카드는 보여주지 않는다**(층키가 없어 과거 폐업 횟수를 셀 수 없다). "같은 호수에 새 신고" 배지와 같은 호수 묶음도 없다(층키가 있어야 판정한다)
- 이력 없음: "이 필지에는 2026년 {월} 기준 식품 업소 인허가 기록이 없어요"

### 4.4 층 이력 `/place/[pnu]/[floor]` (핵심)

순서:
1. **헤더**: 지번 주소 + 층, 도로명 보조
2. **요약 칩**: 거쳐간 업소 {n}곳(2005년 이후) · 폐업 업소 영업기간 중앙값 {x}년 {y}개월 · 지금 영업 중 {k}곳
3. **기준율 카드** (`BaseRateCard`)
   - 표시: "이 층처럼 과거 폐업이 **{bucket_label}**인 자리에 새로 연 가게는 3년 안에 **{rate}%**가 문을 닫았어요."
   - 비교: "과거 폐업이 없던 자리는 {baseline}%였어요."
   - 보조: "{scope_label} {scale_label} {n}곳 기준 · 95% 신뢰구간 {lo}~{hi}% · {snapshot} 데이터" + 신뢰구간 막대(가로, 두 값 비교)
   - 층 규모(T-019b, docs/10 §7.2): 카드의 값은 이 층과 같은 규모의 자리만으로 낸 값이다. `{scale_label}` = `single` "한 점포가 쓰던 층" / `small` "여러 점포가 함께 있던 층(2~9곳)" / `large` "점포가 많은 층(10곳 이상)". 비교 문구의 기준선도 같은 규모다
   - 고정 문구: "참고 통계예요. 이 자리에 열 가게의 성패를 예측하지 않아요." + "어떻게 계산했나요?" → `/methodology`
   - 숨김: "비슷한 이력의 자리가 충분하지 않아(200곳 미만) 통계를 보여드리지 않아요."
   - 숨김(`hidden_reason = "not_confirmed_for_floor_scale"`): 그 규모에서 판정이 깨졌으면(docs/10 §7.3) 카드 대신 **"이 규모의 자리에서는 차이가 확인되지 않았어요"**를 표시한다. 비율·신뢰구간은 보여주지 않고 "어떻게 계산했나요?" → `/methodology` 링크만 둔다
4. **알림** (`notices`): 여러 점포 가능 / 폐업 처리 몰린 날 포함 / 같은 호수에 나중 신고 있음 / 2005년 이전 층 정보 누락
5. **타임라인** (`FloorTimeline`): 세로, 오래된 순. 항목 = 상호 · 업태 · `2011.03 – 2013.08` · `2년 5개월` · 배지(영업 중/폐업 처리 몰린 날/같은 호수에 새 신고) · 같은 호수 그룹은 같은 색 점 + "같은 호수({ho}호)로 신고된 기록"
   - "같은 호수에 새 신고" 배지(`stale_suspect`) 설명: "같은 호수로 나중에 다른 가게가 영업 신고를 했어요. 이 가게의 폐업 신고가 늦어졌을 수 있어요." 같은 호 근거일 때만 보여준다. 면적만 같은 경우(`stale_area_match`)는 화면에 내지 않는다(docs/10 §6, ADR-023)
   - "폐업 처리 몰린 날" 배지(`bulk_closure`) 설명: "이날 {관할 이름}에서 평소보다 훨씬 많은 폐업이 한꺼번에 처리됐어요({n}건). 실제로 문을 닫은 날은 더 이를 수 있어요." 해석("행정 일괄 정리")이 아니라 사실만 쓴다(ADR-020). 관할 이름과 건수는 API가 주는 값만 쓴다 — 응답에 포함하기로 결정했고(2026-10-13), 저장은 T-016, 응답 필드는 T-022에서 docs/30을 고쳐 추가한다
6. **행동**: "이 자리로 정책자금 알아보기"(프로필에 `region.sido_code='11'`, `region.sigungu_code` = PNU 앞 5자리를 저장하고 `/funding`) · "정보가 잘못됐나요?"(정정 요청 시트)
7. 메타데이터: `<title>{지번} {층} 가게 이력 | 가게내비</title>`, 설명에는 평가적 표현 금지

### 4.5 정책자금 마법사 `/funding`
- 상단 진행 막대(단계 n/10), 뒤로 가기, 각 단계 "모름" 버튼
- 단계 정의는 docs/21 §3. 단계마다 `localStorage` 즉시 저장(`gn.profile.v1`)
- 마지막: 입력 확인 화면(수정 링크) → "결과 보기"
- 신용점수 단계: `/funding/credit-bands`로 구간 버튼 생성, 도움말 시트 "신용점수 조회는 점수에 영향을 주지 않아요"

### 4.6 정책자금 결과 `/funding/result`
1. 요약 카드 (docs/21 §5-1)
2. `MissingFactsPrompt`: "이 {k}가지를 입력하면 {m}개 사업을 더 정확히 판정할 수 있어요" → 해당 단계로 딥링크
3. `PlanCard`(need_cover): 단계 번호 · 사업명 · 배분액 · 금리 · 선행 조건 · 공식 링크 버튼("공식 사이트에서 직접 신청") · 경고 칩(order_effect 등)
4. `ProgramVerdictList`: 사업 행 = 이름 + `TriStateBadge` + `AvailabilityBadge` + 금액 범위. 탭하면 이유 문장(템플릿) + 근거 버튼
5. 참고안(max_limit) 접힘 + 부채 경고
6. `BrokerNotice`, `Disclaimer`(확인일·규칙 버전)

### 4.7 폐업 지원 `/closure`, `/closure/result`
- 마법사 단계: docs/22 §3
- 결과: 요약(예상 지원액 범위) · 계획 2안 탭(금액 최대 / 확실성 우선) · `StepTimeline`(날짜 있는 노드는 날짜, 없는 노드는 순서만) · 함정 체크리스트 · **경영개선 지원 카드**("폐업 대신 운영을 이어가는 선택지도 있어요") · 근거·면책

### 4.8 내 사업장 `/profile`
- 저장된 프로필 항목별 보기·수정, "이 기기에서 모두 삭제"(확인 다이얼로그 — 앱 내 모달, 브라우저 `confirm` 금지)

### 4.9 방법론 `/methodology`
섹션: 데이터 출처와 기준일 · 자리(층키) 정의 · 과거 폐업 횟수·3년 내 폐업 정의 · 폐업 처리 몰린 날의 처리(제외 없음·탐지 규칙·서울 전체 100건 기준 세 가지 비교, ADR-020) · 설정을 하나씩 바꿔 본 결과(편의점 포함, 신고 지연 의심 제외, 층 미상 폐업이 있는 필지 제외 — docs/10 §7.3) · 결과(기준율 표, 로지스틱 결과, 시군구별 결과 점그래프, **시간 외 검증 AUC: 개별 예측력은 매우 작다는 사실**) · 한계 · 갱신 주기. 데이터는 `/stats/model-card`.

### 4.10 관리자 `/admin`
- 검수 화면: 좌측 원문(근거 문장 하이라이트, 줄 번호) / 우측 규칙 폼(필드별 승인·수정, `needs_review` 빨간 표시, 자동 검증 결과 배지) / 상단 타이머(필드 편집 시간 자동 측정 → `seconds_spent`)
- 대기열 표, 변경 감지 목록(diff), 평가 실행 이력(지표 + 신뢰구간 표), 정정 요청 처리

## 6. 문구 규칙 (`lib/format.ts`와 일치)

- 해요체. 명령형보다 안내형("신청하세요" → "신청할 수 있어요", 단 기한·금지 안내는 "~해야 해요")
- 금액: `30000000` → `3,000만 원`, `450000` → `45만 원`, `120000000` → `1억 2,000만 원`
- 비율: 소수 첫째 자리 `43.4%`. 신뢰구간 `(95% 신뢰구간 39.2~47.1%)`
- 날짜: `2026년 11월 20일`, 타임라인 기간 `2011.03 – 2013.08`, 기간 길이 `2년 5개월`
- **금지 표현**: 망한 자리, 위험한 자리, 저주, 흉지, 대박, 승인 보장, 대출 확정, 100%, 무조건, 누구나
- 검증하지 못한 해석을 사실처럼 쓰지 않는다: "행정 일괄 정리" 대신 "폐업 처리 몰린 날"(ADR-020), "폐업 신고가 늦어진 것으로 보여요" 대신 "같은 호수로 나중에 다른 가게가 영업 신고를 했어요. … 늦어졌을 수 있어요"(ADR-023)
- 상호는 데이터 그대로 표시하되 평가 문장 안에 상호를 넣지 않는다

## 7. 상태·오류·오프라인

- 로딩: 스켈레톤(레이아웃 이동 없음). 평가 요청 3초 넘으면 "계산 중이에요" 문구
- 오류: 사람이 읽는 문장 + 재시도. `request_id`는 접힌 "문제 신고용 정보"에만
- 오프라인(PWA): 앱 셸과 마지막으로 본 자리 페이지만 표시, 평가는 "인터넷 연결이 필요해요"

## 8. PWA

- `app/manifest.ts`: name "가게내비", short_name "가게내비", display `standalone`, 시작 URL `/`, 아이콘 192/512(maskable 포함)
- Serwist 서비스 워커: 정적 자산 캐시 우선, `/place/*` 네트워크 우선(실패 시 캐시), `/api/v1/*/evaluate`는 캐시 금지
- iOS 홈 화면 추가 안내는 두 번째 방문부터 1회만

## 9. 검색 노출 (SEO)

- **Gate 1 전에는 전체 `noindex`.** Gate 1(정정 요청 처리 체계 포함) 통과 후 기록 2건 이상인 층 페이지만 색인 허용
- `sitemap.ts`: 시군구별 분할 사이트맵(파일당 URL 5만 개 이하)
- 구조화 데이터는 사용하지 않음(평가 정보로 오해될 소지)

## 10. 분석 이벤트 (개인정보 없음, 자체 호스팅 도구)
