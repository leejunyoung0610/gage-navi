| 형식 | CSV, **CP949** ✅. 주소 필드에 줄바꿈이 포함된 행 있음 → CSV 파서로 읽을 것(줄 단위 처리 금지) ✅ |
| 키 | `관리번호` 파일 내 고유 ✅ (`개방자치단체코드-...` 형식) |
| 갱신 | 공공데이터포털 표기 기준 수시. 파일 내 `데이터갱신시점`, `최종수정시점` 존재 ✅ |

**사용 컬럼** (원문 컬럼명 → 내부 필드)

| 원문 | 내부 | 비고 |
|---|---|---|
| 개방자치단체코드 | `jurisdiction_code` | 7자리 (예: 3040000 = 광진구) ✅ |
| 관리번호 | `mgmt_no` | |
| 인허가일자 | `opened_on` | `YYYY-MM-DD` ✅ |
| 영업상태명 | `status_raw` → `status` | `영업/정상`→open, `폐업`→closed, `휴업`→suspended, 그 외→other 🔎(T-016에서 전체 값 목록 확인) |
| 폐업일자 | `closed_on` | 폐업인데 비어 있는 행 서울 27건 ✅ → `closed_on=NULL`, 통계 제외 |
| 소재지면적 | `area_m2` | ㎡ 🔎(단위 표기 없음, 값 분포로 ㎡ 추정 — T-016에서 확인) |
| 사업장명 | `name` | |
| 업태구분명 | `biz_category` | 한식, 분식, 호프/통닭, 경양식, 까페 … ✅ |
| 지번주소 | `jibun_addr` | 서울 100% 존재 ✅. PNU·층 파싱의 1차 소스 |
| 도로명주소 | `road_addr` | 55% 존재(광진구) ✅. 쉼표 뒤 상세에 층·호가 있음 |
| 좌표정보(X), 좌표정보(Y) | `geom` | 평면 직각좌표(중부원점 계열). EPSG:2097 또는 5174로 추정 🔎 T-014 |
| 데이터갱신시점 | `source_updated_at` | |

**사용하지 않는 컬럼**: 전화번호(개인정보 성격 — 화면·DB 정규화 테이블에 저장 금지, raw에만 존재), 종사자 수, 보증액·월세액(대부분 공란) 등.

## 4. 라이선스·이용 조건

- 공공데이터포털 데이터는 데이터별 "이용허락범위"를 T-010/T-050에서 확인해 `data/README.md`에 기록한다. 출처 표기는 화면 하단과 방법론 페이지에 한다.
- 공고 원문은 근거 인용 목적의 짧은 발췌만 화면에 노출하고, 전문은 원문 링크로 안내한다.
