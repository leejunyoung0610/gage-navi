# 21. 정책자금 모듈 (`funding`)

## 1. 목표

- **사용자 질문**: "브로커 없이, 내 조건에서 받을 수 있는 정책자금은 무엇이고 어떤 순서로 신청하면 필요한 돈을 가장 싸고 확실하게 마련하나?"
- **엔진**: docs/20 공통 규칙 엔진. 이 모듈은 프로필→사실 변환, 목적함수 설정, 화면만 가진다
- **기본 목적**: `need_cover` (ADR-017). `max_limit`는 참고안

## 2. 대상 사업 (MVP, 서울)

최종 목록과 프로그램 ID는 **T-060a**(목록·시드)와 **T-060b**(규칙 확정)에서 공고 원문을 확보한 뒤 `program` 테이블 시드로 확정한다.

| 그룹 | 후보 | 비고 |
|---|---|---|
| 소진공 정책자금 (2026 공고) | 일반경영안정자금, 긴급경영안정자금, 신용취약소상공인자금, 대환대출, 재도전특별자금, 청년고용연계자금, 상생성장촉진자금 등 | 2026년 정책자금은 3개 분야 11개 사업(언론 보도). 직접대출/대리대출 구분 |
| 서울 | 서울신용보증재단 보증부 대출, 서울시 중소기업육성자금(소상공인 부문, 이차보전 포함) | 🔎 2026 공고 원문 |

> ⚠️ 2차 출처(토스플레이스 정리글, 2026)에 나온 수치 — 예: 신용취약소상공인자금 NCB 839점 이하·신용관리 교육 이수·직접대출 최대 3천만 원, 대환대출 NCB 919점 이하·연 4.5% 고정·최대 5천만 원 — 는 **후보 탐색용 메모**다. 규칙에는 공고 원문에서 확인한 값만 넣는다(docs/00 §4 원칙 4).

**연도 전환**: 개발 시점(2026-11~12)에는 2026 공고 일부가 마감됐을 수 있다. 2026 공고 = 정답셋·개발용, 2027 공고가 게시되면 "변경 감지 → 재추출 → 재검수 → 새 버전 배포" 데모에 사용한다.

## 3. 프로필 입력 (단계형, 한 화면에 질문 1~3개)

| 단계 | 질문 | 필드 | 입력 방식 | 필수 |
|---|---|---|---|---|
| 1 | 사업장은 어디에 있나요? | `region.sido_code`, `region.sigungu_code` | 서울 고정 + 구 선택 (자리 이력에서 넘어오면 자동) | ✅ |
| 2 | 어떤 업종인가요? | `business.ksic_code` | 업종 검색 → KSIC 5자리 (내부 업종 카탈로그, 🔎 T-061) | ✅ |
| 3 | 언제 개업했나요? | `business.opened_on` | 날짜, 또는 연·월만(→ `[1일, 말일]` 날짜 구간) | ✅ |
| 4 | 직원(상시근로자)은 몇 명인가요? | `business.employees_regular` | 0 / 1~4 / 5~9 / 10명 이상 / 모름 | ⬜ |
| 5 | 최근 1년 매출은 어느 정도인가요? | `business.sales_last_year_krw` | 구간 선택 또는 직접 입력 / 모름 | ⬜ |
| 6 | 신용점수(NCB 기준)는 어느 구간인가요? | `owner.credit_score` | **동적 구간**(docs/20 §3.2) / 모름. 도움말: 조회 방법 안내(조회해도 점수가 내려가지 않음) | ⬜ |
| 7 | 연체나 세금 체납이 있나요? | `owner.has_overdue`, `owner.has_tax_arrears` | 예/아니오/모름 | ⬜ |
| 8 | 지금 이용 중인 정책자금·보증이 있나요? | `history.received`, `history.balance_krw.*` | 목록 선택 + 잔액 구간 | ⬜ |
| 9 | 대표자 나이는? | `owner.age` | 숫자 (청년 조건용, 도움말에 이유 표시) | ⬜ |
| 10 | 자금이 왜, 얼마나 필요한가요? | `need.purpose`, `need.amount_krw` | 운전/시설 + 금액 | ✅ |

- 각 화면 하단: "입력한 정보는 이 기기에만 저장돼요" (ADR-014)
- "모름"은 언제나 선택 가능 → 해당 조건 UNKNOWN + "입력하면 판정돼요" 안내
- 소상공인 해당 여부(`business.is_small_business`)는 업종별 상시근로자 기준으로 파생하되, 기준표는 🔎 T-061에서 법령 원문(소상공인기본법 시행령)으로 확정. 확정 전에는 "소상공인 확인서 발급 가능?(예/아니오/모름)" 질문으로 대체

## 4. 어댑터 (`app/funding/adapter.py`)

```python
def profile_to_facts(p: BusinessProfile, as_of: date) -> Facts
def objective_for(kind: Literal["need_cover", "max_limit"]) -> ObjectiveConfig
def credit_bands(rules: Sequence[Rule]) -> list[CreditBand]   # 경계값 → [lo, hi] 구간, id = "cs_{lo}_{hi}"
```
- 파생 사실은 순수 함수 + 단위 테스트 (경계: 개업 당월, 윤년 2/29, 기준일 = 개업일)
- 프로필에 없는 값은 `None` (기본값 채우기 금지)

## 5. 결과 구성 (화면 상세는 docs/40 §4.6)

1. **요약 카드**: "필요한 {need} 중 {covered}를 이 순서로 마련할 수 있어요" 또는 "확인이 필요한 항목 N개를 입력하면 더 정확해져요"
2. **추천 계획 (need_cover)**: 단계별 사업, 배분액, 금리, 신청 창구(공식 링크), 선행 조건
3. **사업별 판정 목록**: 자격 × 접수 상태 배지, 펼치면 이유 문장 + 근거
4. **참고: 최대 한도안 (max_limit)**: 기본 접힘, 열면 "한도를 최대로 받으면 빚이 늘어나요. 필요한 만큼만 받는 걸 권해요" 경고 고정
5. **브로커 주의 안내** (§6)
6. **면책**: "실제 승인 여부와 금액은 각 기관 심사로 정해져요. 신청 전 공고 원문을 꼭 확인하세요." + 정보 확인일 + 규칙 버전

## 6. 브로커 주의 안내 (고정 콘텐츠)

- "정책자금은 직접 신청할 수 있어요. 승인을 보장한다거나, 수수료·보험 가입을 조건으로 대출을 알선하는 것은 정부가 금지하려는 '제3자 부당개입'이에요."
- 제도 설명 문구 후보(헤럴드경제 2026-04-28 보도 기준): 중기부는 2025년 12월 TF를 꾸리고 신고센터·신고포상금(최대 200만 원)을 운영하며, 중소기업진흥법 개정으로 부당개입을 정의·금지할 계획. **🔎 T-063에서 중기부 공식 자료로 확인한 내용만 화면에 노출**
- 공식 신고 경로 링크 🔎 T-063에서 공식 URL 확인 후 삽입 (확인 전에는 링크 없이 "중소벤처기업부 1357 상담센터" 안내만 — 1357 통합 번호도 T-063에서 확인)

## 7. 이 모듈의 금지 사항 (docs/60 §2 요약)

- 시중은행·민간 금융상품 비교·추천·링크, 금융회사로부터 대가 수령
- 신청 대행, 서류 작성 대행, 사업계획서 작성
- "승인 가능", "대출 확정", "누구나", "100%" 등 결과를 보장하는 표현
- 신용점수 정확값 서버 저장·로그 (구간만 요청 본문에 존재, 로그 마스킹)

## 9. 평가셋 (docs/50 §5와 공유)

정책자금 공고는 공고 1건에 사업이 여러 개라 공고 수가 적다. 정답셋은 **공고 단위로 분할**하고, 2024~2026년 소진공·서울 공고 + 다른 광역지자체의 유사 공고를 포함해 폐업 지원 공고와 합쳐 **공고 30건(dev 18 / test 12)** 을 목표로 한다. 분할은 T-060a에서 후보 목록을 만들 때 미리 정하고(seed 기록), dev부터 라벨링한다. 라벨링은 W2~W8(docs/70 §2).
