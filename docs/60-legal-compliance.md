# 60. 법적 가드레일

> 이 문서는 설계상의 **금지 사항과 확인 목록**이며 법률 자문이 아니다. 정책자금 모듈 공개(Gate 2) 전에 §2.3 항목을 변호사 등 전문가에게 검토받는다. 검토가 끝나기 전에는 정책자금 모듈을 베타 배너 + 비공개 링크로만 둔다(docs/70 §4). §3 검토도 함께 받는 것을 권장한다.

## 1. 서비스 성격 (모든 화면·문서에서 일관되게)

- **무료 정보 제공 도구**다. 신청 대행, 기관 접촉, 서류 작성, 금융상품 판매·중개, 법률·세무 판단을 하지 않는다
- 어떤 기관·금융회사·업체로부터도 대가를 받지 않는다
- 모든 판정은 "공고 원문 기준 참고 정보"이며 최종 판단은 각 기관이 한다

## 2. 정책자금 (`funding`)

### 2.1 관련 제도 (2026-10 조사 기준)
- 중기부는 정책자금 브로커의 수수료 수취·보험 강매 등을 **'제3자 부당개입'**으로 보고 TF·신고센터·신고포상금을 운영 중이며, 중소기업진흥법 개정으로 이를 정의·금지하고 정책자금 컨설턴트 **등록제**를 추진 중이다
- 금융소비자보호법상 대출성 상품의 판매대리·중개는 등록 대상이다

### 2.2 설계상 금지 사항 (위반 코드는 머지 금지)
- [ ] 수수료·성공보수·후원·광고·제휴 수익 없음
- [ ] 신청 대행, 서류 작성, 사업계획서 작성, 기관 담당자 연결 없음
- [ ] 보험·투자상품·민간 대출상품 안내·비교·링크 없음. 링크는 **공고 기관 공식 페이지**로만 (은행 상품 페이지 링크 금지)
- [ ] "승인", "확정", "보장" 표현 없음 (docs/40 §6)
- [ ] 개별 상담(1:1 채팅, 전화) 기능 없음
- [ ] 결과 화면마다 면책 + 공식 링크 + 확인일

### 2.3 전문가 검토 요청 항목
1. 무료·무대가로 공공 정책자금의 자격·신청 순서를 계산해 보여주는 것이 개정 중소기업진흥법의 "제3자 부당개입" 또는 등록 대상 컨설팅에 해당하는지
2. 대리대출(은행 취급) 정책자금을 추천 계획에 포함하는 것이 금융소비자보호법상 중개에 해당할 소지가 있는지
3. 면책 문구의 충분성

## 3. 자리 이력 (`location`)

- **사실만 보여준다**: 인허가 기록(상호, 업태, 기간)과 집계 통계. 자리·건물·업소에 대한 평가, 순위("폐업 많은 자리 TOP 10"), 낙인 표현 금지 (docs/40 §6)
- **개인정보 최소화**: 전화번호 등 개인 연락처는 정규화 테이블·응답·화면에 없음. 대표자 정보는 원천에 없으며 다른 데이터와 결합하지 않는다
- **정정·삭제 요청**: 모든 층 페이지에 요청 버튼. 접수 후 7일 이내 처리(목표), 사실 오류·권리 침해 우려가 확인되면 `record_suppression`으로 숨김. 처리 기록 보관
- **검색 노출**: Gate 1(정정 체계 가동) 전에는 전체 `noindex` (docs/40 §9)
- **출처 표시**: 행정안전부 인허가 데이터, 기준일. 공공데이터 이용허락범위 확인 결과는 `data/README.md`에 기록

## 4. 폐업 지원 (`closure`)

- 변호사·세무사 연결, 업체(철거·집기) 연결 없음 — 알선 대가 관련 법령(변호사법 등) 리스크 원천 차단
- 법률자문·채무조정·세무는 공공 지원사업 정보와 공식 기관 링크로만 안내
- 법정 기한(부가세 확정신고)은 조문 근거와 함께, 휴일 연장 등 세부는 "국세청 안내 확인" 문구

## 5. 개인정보 처리

- 서버는 사업장 프로필을 저장하지 않는다(ADR-014). 요청 본문 로그 금지·테스트로 검증(docs/50 §6)
- 브라우저 저장: 저장 사실 고지, 삭제 기능 제공
- 분석 도구: 자체 호스팅, IP 익명화, 개인 식별 값 미전송(docs/40 §10)
- `/privacy` 페이지: 수집하지 않는 항목, 브라우저 저장, 분석 도구, 정정 요청 메시지 보관 기간(처리 후 1년)

## 6. AI 사용 고지

- 공고 원문 정리에 AI(LLM)를 사용하고 **사람이 모두 검수**한다는 사실을 `/about`과 방법론 페이지에 고지
- 사용자에게 보이는 판정·설명 문장은 AI가 생성하지 않는다(ADR-001, ADR-010)
- 인공지능 기본법(2026년 1월 시행)의 투명성 의무 해당 여부는 Gate 2 전 검토 항목에 포함
