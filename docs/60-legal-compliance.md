# 60. 법적 가드레일

> 이 문서는 설계상의 **금지 사항과 확인 목록**이며 법률 자문이 아니다. 정책자금 모듈 공개(Gate 2) 전에 §2.3 항목을 변호사 등 전문가에게 검토받는다. 검토가 끝나기 전에는 정책자금 모듈을 베타 배너 + 비공개 링크로만 둔다(docs/70 §4). §3 검토도 함께 받는 것을 권장한다.

## 1. 서비스 성격 (모든 화면·문서에서 일관되게)

- **무료 정보 제공 도구**다. 신청 대행, 기관 접촉, 서류 작성, 금융상품 판매·중개, 법률·세무 판단을 하지 않는다
- 어떤 기관·금융회사·업체로부터도 대가를 받지 않는다
- 모든 판정은 "공고 원문 기준 참고 정보"이며 최종 판단은 각 기관이 한다

## 2. 정책자금 (`funding`)

### 2.1 관련 제도 (2026-10 조사 기준)
- 중기부는 정책자금 브로커의 수수료 수취·보험 강매 등을 **'제3자 부당개입'**으로 보고 TF·신고센터·신고포상금을 운영 중이며, 중소기업진흥법 개정으로 이를 정의·금지하고 정책자금 컨설턴트 **등록제**를 추진 중이다
- 금융소비자보호법상 대출성 상품의 판매대리·중개는 등록 대상이다

### 2.2 설계상 금지 사항 (위반 코드는 머지 금지)
- [ ] 수수료·성공보수·후원·광고·제휴 수익 없음
- [ ] 신청 대행, 서류 작성, 사업계획서 작성, 기관 담당자 연결 없음
- [ ] 보험·투자상품·민간 대출상품 안내·비교·링크 없음. 링크는 **공고 기관 공식 페이지**로만 (은행 상품 페이지 링크 금지)
- [ ] "승인", "확정", "보장" 표현 없음 (docs/40 §6)
- [ ] 개별 상담(1:1 채팅, 전화) 기능 없음
- [ ] 결과 화면마다 면책 + 공식 링크 + 확인일

### 2.3 전문가 검토 요청 항목
1. 무료·무대가로 공공 정책자금의 자격·신청 순서를 계산해 보여주는 것이 개정 중소기업진흥법의 "제3자 부당개입" 또는 등록 대상 컨설팅에 해당하는지
2. 대리대출(은행 취급) 정책자금을 추천 계획에 포함하는 것이 금융소비자보호법상 중개에 해당할 소지가 있는지
3. 면책 문구의 충분성
4. **(Gate 1 공개 전에 확인 — 1~3의 정책자금 검토와 별개)** 방문 측정(§5, ADR-027: 기기에 첫 방문 날짜와 "이미 보냈음" 표시만 저장, 서버는 식별자·IP·User-Agent를 저장하지 않음, `/privacy` 고지, 끄는 스위치)이 "고지 + 거부 가능"으로 충분한지, 사전 동의가 필요한지. 방문 측정은 Gate 1부터 쓰므로 Gate 2를 기다리지 않는다. **공개 전 1회 문의하고 답을 기록한다. 답이 "동의 필요"면 공개 전에 동의 방식으로 바꾼다. 답이 없으면 그 사실을 기록하고 진행한다** (docs/50 §7 Gate 1)
5. **(Gate 1 공개 전에 확인 — 항목 4와 같은 방식)** "현재 위치로 찾기"가 기기 위치(좌표)를 받아 가게내비 서버를 거쳐 카카오 좌표→주소 API로 보내고 주소를 돌려주는 것이 위치정보의 보호 및 이용 등에 관한 법률(위치정보법)상 **위치기반서비스사업 신고 대상**인지. 함께 적을 사실: 좌표와 결과를 서버에 **저장하지 않고 로그에 남기지 않는다**, **로그인·회원 가입이 없어** 좌표를 특정인과 연결하지 않는다, 위치는 사용자가 버튼을 눌러 브라우저 위치 권한을 허용했을 때만 받는다. 관련 조문 번호·인용: TODO(🔎 T-104 — 사용자가 국가법령정보센터에서 확인한 뒤 채운다). **공개 전 1회 문의하고 답을 기록한다. 답이 "신고 필요"면 신고를 마치거나 기능을 끈 뒤 공개한다. 답이 없으면 그 사실을 기록하고 "현재 위치로 찾기"만 끈 채 공개한다(지도에서 고르기·주소 검색은 유지)** (docs/50 §7 Gate 1)

## 3. 자리 이력 (`location`)

- **사실만 보여준다**: 인허가 기록(상호, 업태, 기간)과 집계 통계. 자리·건물·업소에 대한 평가, 순위("폐업 많은 자리 TOP 10"), 낙인 표현 금지 (docs/40 §6)
- **개인정보 최소화**: 전화번호 등 개인 연락처는 정규화 테이블·응답·화면에 없음. 대표자 정보는 원천에 없으며 다른 데이터와 결합하지 않는다
- **정정·삭제 요청**: 모든 층 페이지에 요청 버튼. 접수 후 7일 이내 처리(목표), 사실 오류·권리 침해 우려가 확인되면 `record_suppression`으로 숨김. 처리 기록 보관 — 요청 종류·대상·처리 결과·시각은 남기고, 요청자가 쓴 메시지는 처리 후 1년이 지나면 지운다(§5, T-023). 요청 본문은 로그에 남기지 않는다
- **검색 노출**: Gate 1(정정 체계 가동) 전에는 전체 `noindex` (docs/40 §9)
- **출처 표시**: 행정안전부 인허가 데이터, 기준일. 공공데이터 이용허락범위 확인 결과는 `data/README.md`에 기록

## 4. 폐업 지원 (`closure`)

- 변호사·세무사 연결, 업체(철거·집기) 연결 없음 — 알선 대가 관련 법령(변호사법 등) 리스크 원천 차단
- 법률자문·채무조정·세무는 공공 지원사업 정보와 공식 기관 링크로만 안내
- 법정 기한(부가세 확정신고)은 조문 근거와 함께, 휴일 연장 등 세부는 "국세청 안내 확인" 문구

## 5. 개인정보 처리

- 서버는 사업장 프로필을 저장하지 않는다(ADR-014). 요청 본문 로그 금지·테스트로 검증(docs/50 §6)
- 브라우저 저장: 저장 사실 고지, 삭제 기능 제공
- 분석 도구: 자체 호스팅, 개인 식별 값 미전송(docs/40 §10). 방문 측정은 **서버에 방문자 식별자를 보내지 않는다**(ADR-027, docs/70 §5): 기기(브라우저)에는 첫 방문 날짜와 "이미 보냈음" 표시만 저장하고, 서버는 익명 이벤트("첫 방문(날짜)", "7일 안 재방문(첫 방문 날짜)", "도움이 됐나요" 예/아니오 — 모두 날짜만)만 받아 날짜별 합계로만 저장하며 식별자·IP·User-Agent를 저장하지 않는다(봇은 브라우저에서 판단해 보내지 않고 서버는 User-Agent를 읽지 않는다 — ADR-027 개정 2026-10-19). 기본 설계는 **고지 + 거부 가능**: 끄는 스위치를 켜면 아무 이벤트도 보내지 않는다(내 기기 제외와 같은 브라우저 플래그). 충분한지는 §2.3 항목 4로 Gate 1 공개 전에 1회 문의한다. 호스팅 접속 로그에 IP가 남는지는 T-104에서 확인해 아래에 적었다
- **접속 기록의 IP** (T-104 확인, 2026-10-19)
  - **API(uvicorn)**: uvicorn 접속 로그(`uvicorn.access`)가 클라이언트 주소를 남기고 있었다. `app/core/logging.py`에서 주소를 `-`로 바꿔 **API 전체 로그에 IP를 남기지 않는다**. 앱 접속 로그(`app.access`)에는 처음부터 요청 ID·메서드·경로·상태·지연 시간만 있다. 200·422·429·500 응답에서 어떤 로그에도 IP가 없는지 로그 캡처 테스트(`tests/unit/test_logging.py`)로 확인한다
  - **API 호출 제한**: IP 기준 호출 제한(docs/30 §1)은 IP를 **프로세스 메모리에만** 두고 제한 시간(조회·측정 이벤트 1분, 정정 요청 1시간)이 지나면 버린다. 버리는 일은 앱이 1분마다 하므로(`app/core/memory_sweep.py`, 방문이 없어도 돈다) **IP가 메모리에 남는 최대 시간은 마지막 요청부터 1시간 1분**이다(`/privacy` 문구). 주소 검색 캐시(검색어 → 결과, 요청한 사람 값 없음)도 같은 정리로 **최대 24시간 1분** 뒤 지운다. 가짜 시계 테스트 `tests/unit/test_memory_sweep.py`. 디스크·DB·로그에 쓰지 않는다
  - **Caddy** (출처: https://caddyserver.com/docs/caddyfile/directives/log, 사용자 확인 2026-10-19): `log` 지시어가 없으면 접속 로그를 남기지 않는다. v2.7부터 접속 로그에 `remote_ip`·`client_ip`가 기록된다. `format filter`의 `ip_mask`로 가릴 수 있다(`delete`는 IP 필드 예시가 없어 실제 로그로 확인). 설정은 `deploy/Caddyfile`(T-081): 사이트 블록에 `log`를 쓰지 않고, 오류 로그(`http.log.error`)는 전역 `log default { exclude http.log.error }`로 뺀다 — 오류 로그에는 `log` 지시어가 없어도 요청의 `remote_ip`·`client_ip`가 들어간다. **로컬 확인**(2026-10-21, caddy 2.10.2, 정상·404·502 요청 후 `docker compose logs caddy`): 뺐을 때 `remote_ip`·`client_ip` 0줄, 빼지 않았을 때 1줄(`http.log.error`, 502). API 로그(uvicorn 시작 줄의 `0.0.0.0` 제외)의 IP 모양 문자열도 0줄. **운영 VM 확인은 `deploy/README.md` 7단계(🧑) 결과를 받아 여기에 적는다**
  - **API가 보는 클라이언트 주소** (T-081, 2026-10-21 로컬 확인): API는 `--proxy-headers --forwarded-allow-ips *`로 Caddy가 넘긴 `X-Forwarded-For`를 호출 제한 키로 쓴다(주소는 메모리에만, 위 "API 호출 제한"). 클라이언트가 `X-Forwarded-For`(또는 `X-Real-IP`·`Forwarded`까지)를 요청마다 다른 값으로 위조해 Caddy로 125번 보내도 121번째부터 429 — **위조값이 아니라 실제 접속 주소로 셌다.** 대조군으로 compose 네트워크 안에서 API에 직접 보내면 위조가 통과한다(429 없음). API 포트를 열지 않아 밖에서는 Caddy만 거칠 수 있으므로 `*`를 유지한다. 시나리오별 결과와 VM 확인 명령은 `deploy/README.md` 7단계
  - **Vercel** (출처: https://vercel.com/docs/logs/runtime, 사용자 확인 2026-10-19): 런타임 로그 상세에는 IP가 보이지 않지만, "내 브라우저 요청만 보기" 필터가 IP·User-Agent로 맞추므로 **Vercel 쪽에는 IP가 있다.** 런타임 로그 보관은 Hobby 1시간, Pro 1일. 가게내비는 이 기록을 내려받거나 저장·분석하지 않는다. 측정 이벤트는 브라우저에서 API로 바로 보내 Vercel을 거치지 않는다. 배포 후 대시보드 확인은 T-081 🧑
  - `/privacy` 호스팅 문구(2026-10-19 사용자 결정, A안 — 업체 이름·보관 기간 숫자 없음): "웹페이지를 전달하는 호스팅 업체는 업체 정책에 따라 접속 기록(IP 주소 등)을 잠시 보관할 수 있어요. 가게내비는 이 기록을 내려받거나 따로 저장·분석하지 않아요."
- `/privacy` 페이지 (T-104 — **실제로 저장·전송하는 항목과 일치해야 한다.** 저장·전송이 바뀌면 같은 PR에서 고친다): 수집하지 않는 항목, 브라우저 저장(측정 값, 서비스 워커 캐시), 서버 메모리에만 잠시 두는 값(호출 제한용 IP, 주소 검색 결과 캐시), 호스팅 접속 기록, 방문 측정 — 개인정보 보호법 제30조 제1항 제7호에 맞춰 **기기에 저장하는 값, 목적, 끄는 방법**을 적고 끄는 스위치를 둔다 —, 정정 요청 메시지 보관 기간(처리 후 1년 — `jobs.correction_maintenance`와 관리자 목록 조회가 `message`를 빈 문자열로 지운다, T-023)

## 6. AI 사용 고지

- 공고 원문 정리에 AI(LLM)를 사용하고 **사람이 모두 검수**한다는 사실을 `/about`과 방법론 페이지에 고지
- 사용자에게 보이는 판정·설명 문장은 AI가 생성하지 않는다(ADR-001, ADR-010)
- 인공지능 기본법(2026년 1월 시행)의 투명성 의무 해당 여부는 Gate 2 전 검토 항목에 포함
